# 앨범 허브 (구조·근거)

## 평가 페이지 → 앨범 중심 허브로 재설계 · #92, #93
- 근거: `/album/[mbid]`가 "평가 페이지" 단일 스크롤이던 걸 헤더+HubTabs(홍보/갤러리/반응/정보) 3층 구조로 전환. 앨범을 축으로 홍보·갤러리·반응까지 모으는 피벗 방향에 맞춤
- 결과: 헤더(커버/제목/아티스트/HOT 하트) + HubTabs 4탭. 헤더의 HOT 하트가 유일한 좋아요/HOT 투표(핵심 규칙 1, 코멘트 좋아요와 분리)

## HubTabs = 탭 전환형 (pill 아님) · #93 (fix 커밋 126bb29)
- 근거: 스펙상 선택 탭만 내용 교체하는 구조 → 필터 pill(다중 선택 느낌)은 스펙 의도와 안 맞음
- 결과: 균등 4칸 언더라인 탭바로 교체 + 컨테이너 폭을 페이지 정렬 기준(1364px)에 맞춤

## 기존 로직 재사용 원칙 (정보·반응 탭)
- 정보 탭 = 기존 별점 로직(`/api/ratings`), 반응 탭 = 기존 코멘트 로직(`/api/comments`) + `useLikeToggle` 그대로 재사용
- 스타일만 새 디자인 토큰으로 교체, 로직은 손대지 않음 → 회귀 없음을 보장하는 전제. 검증도 "기존 동작이 그대로인지"만 확인하면 됨 (#93 PR 검증 항목)
- 단일 사용처였던 RatingSection/CommentSection/AlbumLikeButton은 삭제하고 `src/components/album/`로 이동
