## 📖 설정 가이드

### 1단계 — 구글 클라우드 프로젝트 만들기
1. https://console.cloud.google.com 접속
2. 프로젝트 선택 드롭다운 → "새 프로젝트"
3. 이름: ARS → 만들기

### 2단계 — 동의 화면 만들기
1. API 및 서비스 → OAuth 동의 화면
2. "외부" 선택 → 만들기
3. 앱 이름, 사용자 지원 이메일, 개발자 연락처 입력
...

### 3단계 — OAuth 클라이언트 ID 만들기
...
1. 이름 작성
2. 승인된 리디렉션 URI/callback 주소 넣기
3. 저장하고 정보 저장(민감 정보 로컬 추가 저장)
