# 00. 피벗 결정/승계 페이지 대장 — ARS (피벗)

> 노션 "관리 문서(피벗 버전)" 원본을 레포로 이관. 후행 문서: [01. PRD](./01_PRD.md)

## 왜 피벗하나?

ARS 피벗 전 버전은 "음악 평가", 디깅이 위주였고 그냥 별점 주고 평가하는 방식이라 **재미 자체가 없음.** (들어오는 사람들을 고려하지 않고 만든 홈페이지)

→ "음악 커뮤니티·홍보 플랫폼"으로 전환. 앨범, 가수를 평가의 대상이 아닌 이슈, 홍보, 커뮤니티의 수단으로 활동.

## 기능 승계/폐기 판단 기준표

기준: 이걸 넣었을 때 피벗 목적에 부합하는가?

| v1 기능 | 판단 | 근거 |
|---|---|---|
| 평점(RatingStars) | 🟡 강등 | 앨범 상세 부가기능으로. 홈 축에서 제외 |
| 랭킹 3종 | 🔴 폐기 | 평점 강등으로 축 이탈 → 월간 TOP/HOT로 대체 |
| 마이페이지 | 🔴 폐기 | 공개 프로필로 흡수(편집·설정 탭) |
| 아카이브 | 🟡 재정의 | 평가 목록 → 앨범 카탈로그/허브 |
| 팔로우/팔로잉 | 🆕 신규 | 팔로우 + 팔로잉(신규) |
| 좋아요 | 🟢 승계 | 갤러리·홍보글 공통 |
| 공개 프로필 | 🟢 승계+확장 | 자기소개글, 팔로워, 팔로잉만 남기기 |
| board_posts | 🟢 승계+확장 | 홍보게시판 board_type 추가 |
| 댓글 | 🟢 승계 | 전 게시판 공통 |
| 월간 TOP/HOT | 🆕 신규 | 랭킹 3종 대체, Hot은 투표/평점 순(평점이 같다면 투표자순 소수점 첫짜리까지 UI로 보여주고 실제 계산은 필요시 소수점 자리를 늘리는 방식) |
| 홍보게시판 | 🆕 신규 | board_type 확장 |
| 갤러리(디시식) | 🆕 신규 | 스키마 재설계 필요 |
| 업데이트/공지사항 | 🟢 승계 | 업데이트, 공지사항 내역 필요 |
| Q/A게시판 | 🟢 승계 | 기존과 동일 |
| 알림 | 🆕 신규 | 업데이트 내역, 팔로우/팔로잉 알림, 댓글 알림 → 커뮤니티 기능 확장 |

## DB 델타 개요

- board_posts: board_type에 'promo' 추가 (홍보게시판)
- gallery: 디시식 카테고리 구조로 스키마 재설계 (P1 핵심 리스크)
- 평점·랭킹 테이블: 평점 유지 / 랭킹 뷰는 월간 집계로 교체
- profiles: 마이페이지 설정 필드 흡수
- 그외 승계 판단 표에 있는 DB 추가 필요
