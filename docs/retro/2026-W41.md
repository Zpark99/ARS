- **권한은 DB에서 막는다** — UI 버튼 숨김은 게이트가 아니다. 권한 작업은 RLS `WITH CHECK`까지 내려가야 끝난 것으로 본다 (#125)
- **UPDATE 정책엔 `WITH CHECK`를 반드시 명시** — `USING`만 두면 신규 행 검사를 `USING`이 겸해 "내 행이면 값 바꿔치기 가능"이 된다. 기존 UPDATE 정책들도 같은 기준으로 재점검 대상 (#125)
