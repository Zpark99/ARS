## 1. 사이트맵 트리

```
ARS  [전역: 다크 테마 · 좋아요(하트 탭) · 댓글 · 로그인=구글 OAuth]
│
├── 홈 (/)  ── 콘텐츠 허브 4섹션
│     ├── ① 월간 앨범(TOP/HOT 캐러셀) + 실시간 피드
│     ├── ② 갤러리 핫글 + 홍보게시판
│     ├── ③ 앨범 허브 리뷰
│     └── ④ 최근 발매 앨범
│
├── 아카이브 (/archive) ──► 앨범 허브 (/album/[id])
│     └── 검색 0 → 등록 요청 (album_requests) 🔒
│
├── 앨범 허브 (/album/[id])  [클릭 진입 전용, 헤더 메뉴 X]
│     └── 탭: 홍보(기본) · 갤러리 · 반응 · 정보
│
├── 갤러리 (/gallery)  ── 팀(아티스트)별
│     ├── /gallery/all           전체 갤러리 디렉토리 🆕
│     ├── /gallery/[artistId]    팀별 갤러리 목록  ⚠️ [cat] 대체
│     │     ├── /write           글 작성 🔒
│     │     └── /[postId]        글 상세
│     └── (구독 🔒 · 개념글/공지 필터)
│
├── 홍보게시판 (/promo)
│     ├── /write                 홍보글 작성 🔒 ([팀이름] 양식)
│     └── /[postId]              홍보글 상세
│
├── 프로필 (/profile/[id])
├── 알림 (/notifications) 🔒
├── Q&A (/board/qa)
├── 업데이트·공지 (/board/update)  [🛡️ 관리자 작성]
├── 검색 (/search)  [앨범·가수·글 3탭]
└── 로그인 (/login)  [구글 OAuth]
```

> **중심 노드 = 앨범 허브**. 홈·아카이브·검색·홍보 연결앨범이 모두 `/album/[id]`로 수렴.
> **아티스트 = 갤러리 + 앨범들의 공통 상위** (아티스트 > 앨범 허브).

## 2. 라우트 표

| 라우트 | 화면 | 설명 | 진입 | 이동 |
|---|---|---|---|---|
| `/` | 홈 | 콘텐츠 허브 4섹션 | 로고·헤더 | 앨범 허브·갤러리·홍보 |
| `/archive` | 아카이브 | 앨범 카탈로그(필터·검색) | 헤더 | 앨범 허브 / 검색0→요청🔒 |
| `/album/[id]` | 앨범 허브 | 앨범 상세(홍보·갤러리·반응·정보 탭) | 클릭 진입 | 홍보글·갤러리글 |
| `/gallery` | 갤러리 홈 | 개념글·인기갤·전체보기 | 헤더 | 각 갤러리 |
| `/gallery/all` 🆕 | 전체 갤러리 | 디렉토리(인기·가나다·신설·검색) | 갤러리 홈 더보기 | 팀별 갤러리 |
| `/gallery/[artistId]` | 팀별 갤러리 | 그 팀 글 목록(전체·개념·공지) | 갤러리·검색 | 글 상세·구독🔒 |
| `/gallery/[artistId]/[postId]` | 글 상세 | 본문·댓글·좋아요 | 목록 | — |
| `/promo` | 홍보게시판 | PromoCard 목록 | 헤더 | 홍보글 상세 |
| `/promo/[postId]` | 홍보글 상세 | 본문·연결앨범·댓글·팔로우 | 목록 | 앨범 허브 |
| `/profile/[id]` | 프로필 | Avatar·소개·팔로우·활동 | 유저 클릭 | 활동 대상 |
| `/notifications` 🔒 | 알림 | NotificationItem 목록 | 헤더 🔔 | 각 대상 |
| `/board/qa` | Q&A | 질문·답변 목록 | 헤더 | 글 상세 |
| `/board/update` | 업데이트·공지 | 공지 목록(🛡️ 관리자) | 헤더 | — |
| `/search` | 검색 | 통합 결과(앨범·가수·글 탭) | 헤더 검색 | 각 대상 |
| `/login` | 로그인 | 구글 OAuth | 헤더/게이트 | 직전 화면 복귀 |

> ⚠️ 앨범 허브 내부 = 탭(홍보/갤러리/반응/정보), [06 Screen-Definitions](./06_Screen-Definitions.md) 확정.

## 3. 접근 권한 (Auth Gating)

| 행위 | 비로그인 | 로그인 |
|---|---|---|
| 열람 (홈·아카이브·앨범허브·갤러리·홍보·QA·업데이트) | ✅ | ✅ |
| 좋아요(하트 탭) · 댓글 · 평점 | 🔒 | ✅ |
| 글 작성 (갤러리·홍보·QA) | 🔒 | ✅ |
| 갤러리 구독 · 팔로우 · 알림 | 🔒 | ✅ |
| 앨범 등록 요청 | 🔒 | ✅ |
| 프로필 편집 | 🔒 | ✅ (본인만) |
| 업데이트·공지 작성 | ❌ | 관리자만 |

> 게이트 정책: 열람은 전면 개방(콜드스타트 이탈 방지), 참여에서 로그인 유도. 🔒 클릭 → `/login` → 복귀. 로그인 = **구글 OAuth 단일** (이메일/비번 없음).

## 4. 핵심 유저 플로우

**F-1. 뮤지션 홍보 루프**
```
로그인 → /promo/write → [팀이름] 새 EP 발매 작성 (앨범 연결)
      → 홈 실시간 피드 노출 → 방문자 발견 → /album/[id] 진입
      → 좋아요(하트)·댓글 → 팔로우 → 다음 발매 시 알림 재방문
```

**F-2. 방문자 탐색 루프 (평가 없이 참여)**
```
/ 홈 월간 HOT → /album/[id] 앨범 허브 → 갤러리 탭 반응 열람
      → 하트 탭(로그인 게이트) → /login → 복귀 → 참여
```

**F-3. 앨범 탐색**
```
/archive → 필터(장르·연도) → /album/[id] → 홍보/갤러리/반응 탭 순회
```

**F-4. 갤러리 탐색 🆕**
```
/gallery → 개념글·인기갤 → /gallery/all 전체 → /gallery/[artistId]
      → 구독 → 팀 새 글 알림
```

## 5. URL · 명명 규칙

- 게시판은 `/board/[type]` 통일하되, 커뮤니티 핵심 **갤러리·홍보는 최상위**(`/gallery`, `/promo`)로 승격.
- 동적 세그먼트: 앨범 = `[id]`, 글 = `[postId]`, 유저 = `[id]`, **갤러리 = `[artistId]`** (팀별).
- 앨범 데이터 출처(Spotify) 라우트는 관리자 영역 분리(공개 사이트맵 제외).

> ⚠️ 실제 구현에서는 앨범 데이터 출처가 Spotify가 아닌 **MusicBrainz + Cover Art Archive**로 확정됨. 라우트도 `/album/[mbid]` 기준. [03_ERD.md](./03_ERD.md) 참고.
